# SQL folder

`Amazon_Sales_Analysis_Queries.sql` contains 35 numbered MySQL analysis sections.

Before running:
- Import the required Excel worksheets into MySQL as tables.
- Confirm the table names and column types.
- Change `USE amazon_sales_analysis;` if your schema has a different name.
- Run one section at a time and validate totals against the intended table grain.

The queries are supplied as source material and have not been executed against a live MySQL server in this packaging step.
